🤖 智能客服 Widget 演示

点击页面右下角的圆形按钮即可打开聊天窗口。本页面模拟一个第三方网站，展示如何把客服组件嵌入任意页面。

嵌入方式 1 — <script> 标签

<script src="/widget/customer-service.js?v=1"></script>
<script>
  CustomerService.init({
    apiUrl: 'http://localhost:8000',
    accent: '#0a66c2',
    position: 'right',          // or 'left'
    autoOpen: false,
    enableUpload: true,
  });
</script>

客服名称、头像、欢迎语会自动从后端「客服信息」读取，不用写在这里。
?v=1 是缓存版本号，更新组件后递增它，否则用户会继续用旧版本。
界面语言也不用传：组件按访客所在地区自动选择（中国大陆 → 简体中文，港澳台 → 繁体中文，日本 → 日语，其他 → 英语），只看浏览器时区和语言偏好，不查 IP， 内网离线也能判断。访客可以在聊天窗口里手动切换，AI 的回答会跟着换语言。 需要写死某种语言时才加 lang: 'ja'。

嵌入方式 2 — iframe

<iframe src="http://localhost:8000/embed?api=http://localhost:8000"
        style="position:fixed;right:20px;bottom:20px;
               width:400px;height:636px;border:0;background:transparent;">
</iframe>

尺寸 400×636 是面板展开后需要的空间，给小了会被裁掉； background:transparent 避免多余区域露出白底。 看实际效果 →
